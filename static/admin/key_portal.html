Zenith API Key Portal

Minimal operator UI for create / list / revoke against /api/v1/admin/keys. Requires an admin key with scope admin:keys. Secrets are shown once on create. Prefer the durable vault (ZENITH_KEY_VAULT_PATH) in staging.

Demo admin secret is for local/sandbox only. Override in real deploys.
